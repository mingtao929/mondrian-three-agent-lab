# 蒙德里安平台中文搭建与源码导读

在 VS Code 选择「文件 → 打开文件夹」，打开平台根目录。在集成终端执行下面的命令。先用 `python --version` 确认 Python 可用。如果 Windows 上 `python` 指向失效的解释器，可用 `py -3`，或在 VS Code 用「Python: Select Interpreter」选择可用解释器后重开终端。

```powershell
python -B -m unittest -v
python -B -m 模块05_实验记录与对照.实验演示 --输出 "$env:TEMP/蒙德里安-分享"
Invoke-Item "$env:TEMP/蒙德里安-分享/回放.html"
```

回放目录可以逐轮切换 A、B、C。前三轮脚本分享线索，接下来各席位利用聊天里的目标移动并旋转。回合同目录内的 `回合.jsonl` 每行包含轮次、实际输入、原始回复、解析动作、执行回执和三份行动后快照。研究者看全部快照，Agent 只拿自己这一轮的视野。

| 顺序 | 先读哪里 | 从输入追到输出 | 推荐动手练习 |
| --- | --- | --- | --- |
| 01 拼图核心 | `拼图核心.py` 的 `Piece.cells`、`Puzzle.move`、`_place`、`is_solved` | 坐标和方向 → 占用格 → 候选位置 → 权限、边界、碰撞检查 → 新棋盘或错误 | 修改学习副本里的棋盘宽度，补一个越界测试。 |
| 02 三方视野与通信 | `三方视野与通信.py` 的 `observe`、`send_message` | 棋盘和由平台指定的席位 → 公共位置、一条私有线索和公共聊天 | 画出 A 知道 B、B 知道 C、C 知道 A 的关系。用断言检查自己的目标没有直接出现在私有线索里。 |
| 03 桌面 Agent 接入与调度 | 先读 `轮次调度.py` 的 `step`，再读 `MCP接入验证.py` 的 `create_app` | 调度器按 A/B/C 取观察 → 调用适配器 → 解析回复 → 执行动作。单独的 MCP 验证入口从凭证确定席位，再开放读取与移动工具。 | 写一个总是返回等待的适配器。随后参考根目录 README 用真实客户端验证 MCP 工具回执。 |
| 04 前端观察界面 | `观察页面.py` 的 `render_page`、`create_server` | 单席位视野 → 格子、线索和聊天 → HTML。浏览器请求由本机 HTTP 服务处理。 | 改 A 的颜色。再次运行观察页测试，确认座标、文字与聊天转义正常。 |
| 05 实验记录与对照 | `实验演示.py` 的 `脚本回复`、`运行实验`、`导出` | 局部观察 → 发言或动作 → 调度器执行 → 逐轮快照 → JSONL 和浏览器回放 | 对照第四轮的输入与回执，找出它使用了谁分享的线索。 |

## 逐模块运行

```powershell
python -B -m unittest 模块01_拼图核心.test_拼图核心
python -B -m unittest 模块02_三方视野与通信.test_三方视野与通信
python -B -m unittest 模块03_桌面Agent接入与调度.test_轮次调度
python -B -m unittest 模块03_桌面Agent接入与调度.test_MCP接入验证
python -B -m 模块04_前端观察界面.观察页面
```

观察页运行后打开 http://127.0.0.1:8767 ，按 Ctrl+C 停止。它提供独立演示棋盘与席位浏览。查看同一场脚本实验的进展请使用第五模块的逐轮回放。

如需复查线索路径，可在本机另跑一场脚本对照，公共聊天机制继续可用，脚本在这一场不主动分享。这用于定位依赖关系，不能据此估计真实 Agent 的协作效果。

```powershell
python -B -m 模块05_实验记录与对照.实验演示 --不分享 --输出 "$env:TEMP/蒙德里安-对照"
```

## 当前的验收边界

脚本演示复用了实际规则、视野、调度和页面渲染。MCP 检查服务与该演示分别运行，现有工具支持观察和移动。把三个真实桌面 Agent 接入同一个实验调度、公共聊天和运行控制，仍需要整合并取得真实客户端回执。正式研究的回放还需要实验编号与版本、运行异常和行为编码，当前回放提供原始证据。
