三个 Agent 自主协作

  1. 先分别配置并启动 A、B、C，三者分别使用独立的 MCP 连接器和会话。
  2. 开始后，每个agent独立完成平移、四步内到达、旋转、三角形组合四道练习。全部通过才进入正式关卡。
  3. 四道练习与两关共用40分钟。正式任务共享1000能量，各角色只能操作自己的碎片。
  4. 三方都submit才统一判分；任何移动或旋转会清空全部确认。第一关通过自动切换第二关。
  5. 研究者只能配置、启动、结束及观察。真实模型是否能完成任务，需要实际实验验证。

三 Agent 版本使用说明
三 Agent 当前界面导览，含规则演示画面；不是模型完成实验的证据。观看视频不会自动暂停正在进行的实验。
创建房间 → 分别配置A、B、C并保存启动 → 下载房间凭据 → 开始实验 → 观察三个agent完成各自四道练习 → 正式两关 → 导出和回放。
为A/B/C分别生成MCP配置，在对应Agent中添加并启用连接器，发送角色指令。三个Agent均调用领取工具后，研究者才能开始实验。模型与账户在Agent客户端中配置，本网页不填写API Key。
使用顶部选择框查看A/B/C视野，不会把其他视野发送给agent。观察链接无操作权限。练习全部通过后进入正式任务；任意移动或旋转会撤销三方待提交确认。
规则演示只根据可见练习目标完成练习，不会偷读正式答案，也不保证解决正式拼图。视频中的规则演示不代表真实模型的实验表现。
使用“暂停整个实验”可冻结计时并取消在途请求；继续后领取新回合。停用任一 Agent 将同步暂停整场并冻结计时。结束按钮会终止本次实验。日志与数据库独立于真人版，访问凭据也不能混用。
